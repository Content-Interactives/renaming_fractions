# Renaming Fractions Interactive

Vite + React app for equivalent fractions and renaming with different denominators.

**Live:** [https://content-interactives.github.io/renaming_fractions/](https://content-interactives.github.io/renaming_fractions/)

Curriculum alignment: [Standards.md](Standards.md).

## Stack

- React, Vite
- Tailwind CSS

## Setup

```bash
npm install
npm run dev
```

## Scripts

| Command | Description |
|--------|-------------|
| `npm run dev` | Dev server |
| `npm run build` | Production build |
| `npm run preview` | Preview `dist/` |
| `npm run lint` | ESLint |
| `npm run deploy` | GitHub Pages |

## Configuration

`vite.config.js`: `base: '/renaming_fractions/'`.

Source: `src/`. Assets: `public/`.
